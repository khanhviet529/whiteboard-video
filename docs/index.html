Whiteboard Video Uploader

A personal, self-hosted tool that uploads the operator's own whiteboard-animation videos to their own TikTok account.

What it does

The tool renders short educational whiteboard-animation videos about software engineering topics, then uploads them to the TikTok account of the person running it. It is a command-line program with a small local web page for pressing “upload”. It runs entirely on the operator's own computer.

There is no service, no server, and no other users. Nothing is hosted for anyone else. The operator installs the tool on their own machine, authorizes their own TikTok account, and uploads their own videos.

How it works

  • Videos are generated locally from plain-text scripts, rendered to 1080×1920 MP4 with an AI-generated Vietnamese voice-over.
  • The operator authorizes their own TikTok account once, using TikTok's standard Login Kit OAuth flow.
  • The resulting access token is stored in a file on the operator's own computer and is never transmitted anywhere except to TikTok.
  • Videos are uploaded through TikTok's Content Posting API using FILE_UPLOAD. Uploads default to the creator's inbox as a draft, which the operator then finishes and publishes inside the TikTok app.
  • Because the narration is synthesized, every upload sets TikTok's is_aigc flag so the AI-generated content is disclosed.

Which TikTok data it uses

  • video.upload — send a video file to the operator's own TikTok inbox as a draft.
  • video.publish — post a video directly to the operator's own profile.
  • video.list, user.info.basic — read the view, like, comment and share counts of the operator's own posts, shown on the local page so the operator can see how their videos performed.

The tool never reads, stores, or transmits data about any other TikTok user.

Source code

The tool is open source: github.com/khanhviet529/whiteboard-video (the uploader lives in the dang/ directory).
